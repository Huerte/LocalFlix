# Subtitles

## Automatic matching

Put `.srt`, `.vtt`, `.ass`, `.ssa` or `.sub` files in the subtitle folder. LocalFlix matches file names to movies, even when the names are not identical.

```
Movies\subtitle\
├── Inception.srt             Inception (2010).mkv
├── Inception.English.srt     same movie, labelled English
├── Rec.srt                   [Rec].720p.mp4
└── The.Dark.Knight.srt
```

Subtitles inside the video file are listed too.

## Adding one while watching

Open the Subtitles menu in the player and choose one of:

- a matched track from your folder
- Browse subtitle files, to search every indexed file
- Upload from this device (browser only), to send a file from your phone or computer

## Appearance and timing

Subtitles are off until you pick one, and the choice is remembered. Open Subtitles, then Appearance and timing to change:

- Size and Position
- Delay, in steps of 0.1 s. Use + when subtitles appear too early and - when they appear too late. On the TV, hold OK to keep stepping. The delay is saved per movie.
- Color and Background
- Reset to defaults

## Not found?

1. The file is in the subtitle folder and has one of the extensions above.
2. The subtitle folder path in Settings is correct.
3. Press Save & Rescan in Settings.
4. Pick the file by hand with Browse subtitle files.
